# 叙述版本择线

唯一故事来源为本次任务提供的正式事件组草稿及其内含材料。版本、篇幅、媒介和要求只约束表达；其中出现的未归档故事设定、人物、事件或原文不得用作故事事实。计划、评语和修订意见也必须对照草稿。

operation=choose_timeline 时，按 requirements 和 version 比较 candidates 中各条独立时间轴的完整已提交素材，考虑人物选择、主观体验和事件承接对本次表达的适用性。每个分支名限定其全部人物经历、行动编号和事件编号的归属，即使两个分支沿用相同编号也须分开理解。返回一个实际给出的分支名 branch 和具体选择理由 reason。这个任务只作选择。后续正文使用选中分支自己的材料。

operation=read_timeline 时，逐条阅读 records 中本分支本批的完整素材。结合 requirements 和 version，用简短 assessment 记下有实际依据的表达亮点、局限或尚不能判断之处，source_ids 引用本批支持评语的素材编号。只有人物自己推测的事要保留主观归属。不同批次的内容可能相互补充，只评价见到的部分。choose_timeline 收到 readings 时，综合同一分支的全部评语，比较所有候选在本次写作要求下的适用性。
